# Open WebUI CFM

Home Assistant add-on for Open WebUI.

Open WebUI provides a self-hosted web interface for AI models and supports:

- OpenAI
- Anthropic Claude
- Google Gemini
- Ollama
- OpenAI-compatible APIs
- Local LLM servers
- LiteLLM
- OpenRouter
- Other compatible providers

## Installation

Add this repository to Home Assistant:

[https://github.com/cerferre/open-webui-cfm](https://github.com/carferrer/open-webui-cfm)

Then install:

Open WebUI CFM

## Access

Open WebUI can be accessed directly from the Home Assistant sidebar using Ingress.

Direct network access is also available through port 3000 by default.
